#NetMatters company site - mirror site project

Multiple page company website featuring general and service information, recent news, and a contact form.

##Tech Stack
html, CSS/Sass, JavaScript, PHP/Laravel

##Local Setup
- php version 8 or later
- a web browser
- a Sass compiler
- composer (PHP package manager)
- install dependencies, from root folder -> composer install
- run locally with -> php localhost:8000 -t Public

#Pages
##Home
- Page featuring sticky header menu with links to services
- carousel displaying services
- "our services" cards
- carousel displaying company awards and associates
- client testimonials
- news article cards 
- client carousel 
- footer with additional services links and social media links.

##contact
- Contact Page with site wide navigation links in sticky header
- office locations 
- contact form with frontend and backend validation
- footer with services links and social media links
